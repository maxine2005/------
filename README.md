# 吴美薪 · 产品设计师作品集

React + Vite 单页作品集初版。作品素材按原压缩包目录保存在 `public/作品集/`，简历图片位于 `public/resume.jpg`。

## 本地运行

需要安装 Node.js。首次运行时在项目目录执行：

```bash
npm install
npm run dev
```

Vite 会输出本地预览地址。生产构建使用 `npm run build`，构建预览使用 `npm run preview`。

## 视觉方向

- **关键词：** 清晰、克制、研究驱动、结构感、可触达、精密但有人味。
- **视觉线索：** 以作品渲染中的暖灰、白色产品和黑色结构为底；用档案标签、细分隔线、编号与宽留白呈现设计过程；橙色只用于交互提示和重点标记。
- **布局：** 面向桌面宽屏设计，内容区在约 1700px 视口下保持适度行宽，并为窄屏提供响应式布局。

作品目录保留了原始顺序和文件夹层级。第 4 项“可视化设计”目录在压缩包中为空，因此页面保留目录项并标明当前没有可展示素材。
